# Vanta Studio — native macOS app

A real, native macOS IDE for Vanta — SwiftUI + AppKit, no webview. Unlike the
browser IDE (which runs Vanta in WebAssembly), this runs your code **natively
through python3 at full speed**, with real files on disk.

![native](../../assets/logo.png)

## Build & run

```bash
brew install xcodegen          # if you don't have it
cd app/studio
xcodegen generate              # creates VantaStudio.xcodeproj
open VantaStudio.xcodeproj      # press Run (Cmd-R) in Xcode
```

Requires macOS 14+, Xcode, and `python3` on the machine (the app bundles the
Vanta interpreter and standard library and shells out to your system python3).

## What it does

- **Native code editor** with Vanta syntax highlighting (NSTextView) and a
  line-number gutter.
- **Runs Vanta natively** — bundles `vanta.py` + `lib/` as app resources and
  runs your file via `python3`, streaming output to a console. Fast.
- **Interactive input** — a `›` field appears while a program runs so `ask`
  works (type a line, press Return).
- **Real files** — open/save `.va` files, tabs, a file sidebar, and a list of
  bundled example programs.
- **Vee, the AI assistant** — a native side-panel that writes Vanta for you.
  Because it calls providers with `URLSession` (not a browser), there are **no
  CORS limits**: OpenRouter, Anthropic, **Ollama Cloud**, and **NVIDIA NIM** all
  work directly. Generated code blocks get one-click **Apply** / **New file**.
- **Menus & shortcuts** — Cmd-R run, Cmd-. stop, Cmd-N new, Cmd-O open, Cmd-S save.

## Notes

- The native app focuses on console Vanta. The **canvas/game API** (Snake,
  drawing) is browser-IDE-only — it needs the JS canvas host, which this native
  build doesn't include.
- The `.xcodeproj` is generated by XcodeGen (`project.yml`), so it isn't checked
  in — run `xcodegen generate` after cloning.
- The app is unsandboxed (so it can spawn `python3` and read/write your files);
  fine for a local dev tool, not configured for the App Store.
